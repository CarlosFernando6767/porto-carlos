# Portofolio Carlos Fernando

Situs portofolio pribadi Carlos Fernando — pelajar kelas 12 SMA Kasih Kemuliaan dan peminat Sistem Informasi.

## Isi
- Beranda, Tentang, Belajar, Keahlian, Proyek, Kontak
- Formulir pesan dengan template yang membuka WhatsApp
- Mendukung mode terang dan gelap, responsif di HP

## Struktur
```
porto-carlos/
├── index.html
├── assets/
│   └── foto-carlos.jpg
```

## Menjalankan
Buka `index.html` di browser, atau aktifkan GitHub Pages:
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)`.
